# Piezas reutilizables

Código en `main`. Guías en `docs/reuse/` y ramas de referencia:

| Rama | Para qué |
|------|----------|
| `reuse/form-keyboard-nav` | ↑↓ entre campos + Enter para enviar |
| `reuse/name-capitalization` | Nombres con mayúscula inicial |
| `reuse/excel-export` | Exportar tablas a `.xlsx` |
| `reuse/pdf-contrato-abono` | PDF de contrato al crear abono |

Cómo usar: `git checkout reuse/<nombre>` o copiá los archivos listados en cada guía desde `main`.
